# TinyVibes Liquid V2 Playtest

Technical playtest focused on the intended interaction model:
- Liquid surface is clipped to the circular planet, while object layer can gently overflow.
- Liquid shape is organic and independent from the source object's silhouette.
- Coverage grows through repeated placement of the same liquid family.
- Tap a placed object to rotate +15 degrees.
- Drag a placed object to move it.
- Placement has a small pop/ripple response.
- Tier controls object size, liquid footprint, and motion intensity.
- 20 Cup Test demonstrates progressive coverage and mixed-family composition.

This is a playtest, not final production UI.
